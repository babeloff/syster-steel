= How diagrams are rendered to SVG
:description: SVG generation via layout-rs, with plantuml as an optional manual step
:icons: font

== How SVG is generated

SVG files are produced automatically during diagram generation — no separate
rendering step is needed.
Running either of the main generation tasks is sufficient:

[source,shell]
----
pixi run gen-diagrams   # campaign model → render/
pixi run gen-self       # self-documenting model → wisdom/diagrams-gen/
----

Under the hood, `dot.scm` generates a DOT-language graph for each diagram type,
and the `layout/render-dot` Rust binding (backed by the `layout-rs` crate)
applies the Sugiyama hierarchical layout algorithm and writes the SVG directly —
entirely in-process.  No Java, no external binary, no network access.

== Output artefacts

For each diagram type, both tasks produce:

[cols="1,3"]
|===
| File | Description

| `<name>.puml` | PlantUML source text, generated by `plantuml.scm` via Handlebars templates.
  Kept for reference and for manual plantuml rendering.
| `<name>.svg`  | Rendered SVG, generated by `dot.scm` + `layout/render-dot`.
  This is the primary output used in documentation.
|===

== Re-running generation

If you modify a SysML model or a Steel script and want to regenerate diagrams:

[source,shell]
----
pixi run gen-self       # regenerate wisdom/diagrams-gen/*.svg
pixi run gen-diagrams   # regenerate render/*.svg
----

No extra steps are required; SVG is produced as part of generation.

== Optional: rendering .puml files manually with plantuml

The `.puml` files are plain text and can be rendered with a locally installed
`plantuml` if you want PNG, PDF, or a different SVG rendering style.
plantuml is *not* a project dependency; this is entirely optional.

Verify plantuml is available:

[source,shell]
----
plantuml -version
----

Render a single file to SVG:

[source,shell]
----
plantuml -svg wisdom/diagrams-gen/pipeline-flow.puml
----

Render to PNG:

[source,shell]
----
plantuml -png wisdom/diagrams-gen/pipeline-flow.puml
----

Render all `.puml` files in a directory:

[source,shell]
----
plantuml -svg wisdom/diagrams-gen/*.puml
----

For large models that exceed plantuml's default output size limit:

[source,shell]
----
plantuml -svg -DPLANTUML_LIMIT_SIZE=16384 vehicle-bdd.puml
----
