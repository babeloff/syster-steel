= How to load a SysML v2 model
:description: Parsing a SysML file and querying its symbols from Steel scripts
:icons: font

== Prerequisites

The syster-base functions are registered automatically when `syster-steel` starts.
No `require` is needed — `syster/parse-file`, `hir-symbol/*`, and related functions
are available in every script and REPL session.

See xref:../refer/syster-base-bindings.adoc[syster-base Steel bindings] for the full API.

== Parse a file

[source,scheme]
----
(define model (syster/parse-file "path/to/model.sysml"))
----

`syster/parse-file` returns a `SysmlModel` value,
or raises an error if the file cannot be read.

== Extract all symbols

[source,scheme]
----
(define symbols (syster/file-symbols model))
----

Returns a flat list of `HirSymbol` values representing every element in the
model, including nested members.
The list order matches definition order in the source file.

== Filter symbols by kind

[source,scheme]
----
(define (symbols-of-kind syms kind-str)
  (filter (lambda (s)
            (string=? (hir-symbol/kind s) kind-str))
          syms))

(define part-defs (symbols-of-kind symbols "PartDefinition"))
(define port-defs (symbols-of-kind symbols "PortDefinition"))
(define pkgs      (symbols-of-kind symbols "Package"))
----

See xref:../refer/syster-base-bindings.adoc#symbolkind-strings[SymbolKind strings]
for the complete list.

== Find a symbol by qualified name

[source,scheme]
----
(define (find-by-qname syms qname)
  (let loop ([ss syms])
    (cond [(null? ss) #f]
          [(string=? (hir-symbol/qualified-name (car ss)) qname) (car ss)]
          [else (loop (cdr ss))])))

(define engine (find-by-qname symbols "VehicleModel::Engine"))
----

== Get direct children of a symbol

Symbols are a flat list;
children share a qualified-name prefix with their parent.

[source,scheme]
----
(define (direct-children syms parent-sym)
  (let* ([pqn    (hir-symbol/qualified-name parent-sym)]
         [prefix (string-append pqn "::")]
         [depth  (+ 1 (length (string-split pqn "::")))])
    (filter (lambda (s)
              (let ([sqn (hir-symbol/qualified-name s)])
                (and (starts-with? sqn prefix)
                     (= (length (string-split sqn "::")) depth))))
            syms)))
----

== Work with relationships

[source,scheme]
----
(define rels (hir-symbol/relationships some-sym))

(for-each
  (lambda (r)
    (displayln
      (string-append
       (hir-rel/kind r) " -> " (hir-rel/target r))))
  rels)
----

Relationship kinds: `"TypedBy"`, `"Specializes"`, `"Redefines"`, `"Subsets"`,
`"Satisfies"`, `"Performs"`, `"Verifies"`.

== Load a model split across multiple files

A large model can be split into multiple `.sysml` files that each re-open
the same package.
Parse each file independently and concatenate the symbol lists:

[source,scheme]
----
(require-builtin steel/filesystem)

(define (load-sysml-directory dir)
  (apply append
    (map (lambda (f)
           (syster/file-symbols (syster/parse-file f)))
         (glob (string-append dir "/*.sysml")))))

(define symbols (load-sysml-directory "data/campaign"))
----

If the directory has sub-directories (for example, one per campaign instance),
extend the pattern:

[source,scheme]
----
(define (load-campaign-symbols dir)
  (define top-files   (glob (string-append dir "/*.sysml")))
  (define alpha-files (glob (string-append dir "/alpha/*.sysml")))
  (apply append
    (map (lambda (f) (syster/file-symbols (syster/parse-file f)))
         (append top-files alpha-files))))

(define symbols (load-campaign-symbols "data/campaign"))
----

Each `syster/parse-file` call is independent.
Cross-file qualified-name references work in the SysML source but are not
resolved at the `HirSymbol` level — use `syster/find-by-name` or
`syster/find-by-qname` on the concatenated symbol list instead.
