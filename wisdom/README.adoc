This directory follows the https://diataxis.fr/[Diátaxis] documentation framework.
Each subdirectory serves a distinct purpose and a distinct reader need.

[cols="1,1,2"]
|===
| Directory | Diátaxis type | Serves

| `tutor/`
| Tutorial
| Learning — guided, step-by-step exercises

| `instruct/`
| How-to guide
| Doing — recipes for specific goals

| `explain/`
| Explanation
| Understanding — concepts and design decisions

| `refer/`
| Reference
| Information — precise, complete descriptions
|===

Scheme scripts (`.scm`) that act as reusable libraries live alongside their
reference documentation in `refer/`.

NOTE: syster-steel is an *embedded* Steel Scheme engine.
The `steel-core` crate provides the VM;
syster-steel adds a CLI, a custom REPL, and domain-specific bindings.
See xref:explain/steel-as-extension-language.adoc[Why Steel Scheme as the extension language]
for the full explanation.
